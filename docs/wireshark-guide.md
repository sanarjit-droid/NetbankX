# Wireshark: Synthetic .pcap Export & Network Analysis Guide

PaySafe provides two distinct ways to analyze computer network traffic:
1. **Synthetic `.pcap` Export (High-Fidelity Wire Simulation):** Export an authentic, RFC-compliant binary Libpcap (`.pcap`) trace of any banking simulation run that you can double-click and open directly in desktop **Wireshark** or inspect via the in-browser **Wireshark Frame Dissector**.
2. **Live Loopback Capture:** Capture real HTTP/TCP packets exchanged between your browser and the local Node.js Express server on port 3000.

---

## 1. Synthetic `.pcap` Export & Wireshark Inspection

Every time you initiate a transaction simulation in the **Network Simulator** tab, the PaySafe engine synthesizes a byte-for-byte authentic Libpcap 2.4 file reflecting the exact multi-hop route and security events.

### Step-by-Step Instructions:
1. Navigate to the **Network Simulator** tab in PaySafe.
2. Choose a sender and recipient (e.g. `CUST-01` Aarav Mehta $\to$ `CUST-07` Kabir Rao).
3. (Optional) Toggle **"Deliberately tamper packet in transit"** to simulate an adversary Man-in-the-Middle attack, or set a packet loss probability.
4. Click **▶ Send Transaction & Transmit Packet**.
5. Once complete, click **📥 Download .pcap** (in the Run Metrics banner or the timeline header).
6. Double-click the downloaded `paysafe-sim-xxxxxx.pcap` file to open it in **Wireshark** (or run `tshark -r <file>.pcap`).
7. Alternatively, click **🔍 Inspect Dissector** to inspect the live frame dissection directly in the web browser!

### Network Topology IP & MAC Addressing Scheme:
| Node Tier | Identifier | IP Address | MAC Address | Role |
| :--- | :--- | :--- | :--- | :--- |
| **Level 0 (Backbone)** | `HQ-CORE` | `10.0.0.1` | `02:00:0a:00:00:01` | HQ Core Gateway Router |
| **Level 1 (Regional)** | `REG-A` / `REG-B` / `REG-C` | `10.1.0.1` / `10.2.0.1` / `10.3.0.1` | `02:00:0a:0x:00:01` | Regional Core Routers |
| **Level 2 (Branch)** | `BR-A1` … `BR-C2` | `10.1.1.1` … `10.3.2.1` | `02:00:0a:0x:0y:01` | Branch Gateway Routers |
| **Level 3 (Customer)** | `CUST-01` … `CUST-18` | `10.1.1.101` … `10.3.2.103` | `02:00:0a:0x:0y:6x` | Customer Endpoints |

### What Wireshark Will Reveal:
- **Layer 2 (Data Link - ARP):**
  - Frame 1: ARP Request (`Who has 10.1.1.1? Tell 10.1.1.101`) broadcast to `ff:ff:ff:ff:ff:ff`.
  - Frame 2: ARP Reply (`10.1.1.1 is at 02:00:0a:01:01:01`).
- **Layer 4 (Transport - TCP 3-Way Handshake):**
  - Frame 3: `TCP [SYN]` (ClientPort $\to$ Port 8443, Seq=0, Win=64240).
  - Frame 4: `TCP [SYN, ACK]` (Port 8443 $\to$ ClientPort, Seq=0, Ack=1).
  - Frame 5: `TCP [ACK]` (Seq=1, Ack=1).
- **Multi-Hop IP Routing & TTL Decrement:**
  - As the packet traverses each router hop (`CUST-01` $\to$ `BR-A1` $\to$ `REG-A` $\to$ `HQ-CORE` $\to$ ...), Wireshark shows the Ethernet Source/Dest MAC addresses updating per interface, while the IP addresses stay end-to-end, and the IP `Time to Live (TTL)` decrements by 1 per hop.
- **QoS & Checksums:**
  - IPv4 Checksum (RFC 791) and TCP Checksum (RFC 793 pseudo-header) are computed and verified as `[Good]`.
  - IP DSCP field set to `0xb8` (Expedited Forwarding for Banking).
- **Packet Loss & Retransmission:**
  - If packet loss occurs, Wireshark natively detects duplicate sequence numbers after the RTO and flags: `[TCP Retransmission]`.
- **Adversary Tampering & Security Rejection:**
  - If tampered, the payload frame shows corrupted ciphertext bits, immediately followed by:
    - **ICMP Destination Unreachable:** Type 3, Code 13 (`Communication administratively filtered`).
    - **TCP Reset:** `TCP [RST, ACK]` from the receiving security router immediately aborting the socket.
- **Following the TCP Stream:**
  - In Wireshark, right-click any TCP packet and select **Follow $\to$ TCP Stream**. You will see the complete ISO 20022 authenticated JSON payload with AES-256-GCM hardware tags and the HTTP 200 OK ledger response.

## 2. Live Loopback Capture (Browser-to-Express Server)

If you want to observe actual HTTP requests generated by your browser while clicking around the app:
1. Start the app with `npm start` (listening at `http://localhost:3000`).
2. Open Wireshark and select the **Adapter for loopback traffic capture** (`Npcap Loopback Adapter` or `lo0`).
3. Set filter: `tcp.port == 3000`.
4. Sign in, click buttons in the app, and observe HTTP GET/POST requests and JSON API responses.
